# Rural Auction Hub

Crie a estrutura inicial de uma plataforma profissional de leilões rurais, inspirada na organização e experiência de navegação de grandes sites de leilões, mas com identidade visual e código próprios.
Nesta primeira etapa, NÃO implemente banco de dados, autenticação, pagamentos ou sistema real de lances.
Crie apenas o frontend e a estrutura das páginas.
Páginas necessárias:
Home
Lista de leilões
Página de detalhes de um leilão
Página de detalhes de um lote
Login
Cadastro
Minha conta
Painel administrativo
A Home deve ter:
Header profissional
Logo
Menu de navegação
Banner principal
Seção de próximos leilões
Cards de leilões
Seção de lotes em destaque
Informações sobre a empresa
Footer completo
O visual deve ser profissional, moderno e adequado ao mercado de leilões de gado e propriedades rurais.
Use componentes reutilizáveis e deixe a estrutura preparada para posteriormente adicionarmos banco de dados e funcionalidades reais.
Priorize código limpo, responsividade para desktop e celular e uma arquitetura fácil de expandir.
